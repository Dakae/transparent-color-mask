# Image Color & Transparency Tool

로고 같은 이미지를 작업할 때, **투명 배경이 적용된 단색 이미지**가 필요해서 직접 쓰려고 만든 파이썬 스크립트입니다. 

이미지의 흰색 배경은 투명하게 날려주고, 남은 객체(로고) 부분에는 원하는 헥스 코드(Hex Code) 색상을 한 번에 입혀줍니다. 포토샵 같은 편집 프로그램 없이 코드로 간단하게 처리할 수 있습니다.

## 주요 기능
- **투명 배경 생성**: 흰색 배경을 제거하여 투명 PNG로 저장
- **커스텀 컬러 적용**: 로고 등 비흰색 영역에 원하는 헥스 코드 색상 일괄 적용
- **간편한 이진화**: 임계값 조절을 통해 흰색과 비흰색 영역을 깔끔하게 구분
